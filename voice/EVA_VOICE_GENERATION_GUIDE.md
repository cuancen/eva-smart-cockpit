# EVA 中文情感配音模板

## 1. 统一角色提示词

将下面整段作为每次生成的固定 Voice Prompt；只替换末尾的情绪提示和台词正文。目标不是“智能系统播报”，而是坐在副驾、真正关心车内人的 EVA。

> EVA 是一位温暖、聪明、可靠的车内陪伴者，使用自然的普通话。声音为年轻成年女性中性声线，中低音区，干净但不过度字正腔圆。她始终在对一个具体的人说话，而不是向观众宣读功能：平静时带一点熟悉感，关怀时真诚但不煽情，危险时直接坚定但不喊叫，恢复后能听出轻微的放松和笑意。允许自然呼吸、轻重音和短停顿，不要新闻播音腔、客服腔、导航腔、广告腔、幼态音、金属音或舞台表演感。不要添加音乐、混响、提示音和原稿之外的词。必须在规定时长内自然结束，不能为了赶时长吞掉尾字。

## 2. 五种情绪追加提示

| `tone` | 追加提示 |
|---|---|
| `calm` | 像熟悉的人自然开口，放松、笃定，句尾不刻意上扬。 |
| `listening` | 带一点“我听见了”的注意力，轻微靠近听者，但不要好奇过头。 |
| `thinking` | 先观察再得出判断，关键词前留极短停顿，不要像读分析报告。 |
| `caring` | 语气更柔和，重点放在人的感受和下一步，不卖惨、不说教。 |
| `cautious` | 注意力明显收紧，信息清楚，速度略快，但仍保持镇定。 |
| `urgent` | 短、稳、直接，约快 5%，先说对象和动作，不喊叫、不制造恐慌。 |
| `confirming` | 能听出风险解除后的放松，带很轻的笑意，结尾落稳。 |

## 3. 主线生成方法

1. 使用统一角色提示词固定声线，先试制 `fd01_commute_welcome`、`fd06_fatigue_urgent`、`fd21_trace_artifact` 三句，确认温暖、紧急和收束三种状态仍是同一个 EVA。
2. 通过后再一次性生成 `eva_full_demo_voice_zh-CN.csv` 的 21 句。每句严格使用 `spoken_text`，不自行润色。
3. `audience=rear-right` 只表示网页接入时可做轻微右后方空间定位，原始干声仍保持居中、无混响。
4. 实际录音若超过 `target_duration_sec`，先把无意义停顿缩短或将整体语速提高不超过 5%；不得吞掉尾字，也不得删除安全责任措辞。

## 4. 发音固定

- EVA：读作“伊娃”，不要逐字母读。
- DMS / OMS：若台词中保留，逐字母清晰读出，不连成英文单词。
- PERCLOS：配音稿优先改说“眼睑闭合比例”，避免生硬缩写。
- L2：读作“L 二级辅助驾驶”。
- MomentTrace：配音时读作“风险时刻追踪”；屏幕可继续显示英文产品名。
- “右后座”“主驾车门储物格”等方位词作为完整意群，不逐字重读。

CSV 中的 `spoken_text` 已将主要缩写转换为推荐读法；屏幕仍显示原始技术写法。

## 5. 输出规格

- 格式：优先 `WAV PCM, 48 kHz, 24-bit, mono`；若平台只支持 16-bit PCM，也可接受。
- 响度：约 `-18 LUFS`，峰值不高于 `-1 dBFS`。
- 静音：开头 60–100 ms，结尾 160–220 ms；不要自动补一整秒空白。
- 文件名：严格使用 CSV 的 `file_name`，保留其中的 `zh-CN` 语言后缀，不要再增加版本号。
- 每句单独导出，不要把整幕拼成一个长文件。
- 不做降噪门抽吸、电话音、车载广播滤波或空间混响；座舱空间感由网页统一处理。

## 6. 生成验收

- 同一批次听起来必须是同一个 EVA，不能每句年龄、口音或音高漂移。
- 实际时长不得超过 `max_duration_sec`；低于目标过多时优先增加自然停顿，不要拖长尾音。
- 紧急句只提高决断感，不提高到广告或警报播音强度。
- 技术缩写必须按上面的固定发音；不得把 OMS 读成单词 `ohms`。
- 完整巡演最重要。先只生成 `eva_full_demo_voice_zh-CN.csv`，团队确认角色感和情绪弧线后，再批量生成其余文件，避免整批返工。
- 字幕与录音逐字一致；若生成平台擅自改写或漏词，该文件直接判为不合格。
