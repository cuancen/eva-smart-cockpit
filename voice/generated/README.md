# Returned audio goes here

Place generated WAV files in this folder without renaming them. Keep the CSV manifests beside the files when handing the pack back so duration and tone can be validated before application integration.

Start with the 21 exact filenames from `../eva_full_demo_voice_zh-CN.csv`. Keep one dry voice file per `voice_id`; spatial placement is added by the application later.

Do not add music or sound effects to individual lines.
